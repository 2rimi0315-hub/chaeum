HOW IT WORKS

프로그램별 코드를 그대로 사용해요

‘읽고 이해하기’의 기존 로그인은 유지하고, 새 프로그램은 통합 홈에서 각각 개별 코드를 발급합니다.

01

프로그램 선택

첫 화면에서 사용할 치료 도구를 고릅니다.

02

개별 코드로 로그인

프로그램마다 별도로 발급한 6자리 숫자 코드를 입력합니다.

03

해당 프로그램에서 기록

기존 설명글 기록은 유지하고, 신규 프로그램의 기록은 프로그램별로 분리해 저장합니다.

기존 계정·자료 유지 · 통합 홈은 로그인 입력을 수집하지 않습니다. 신규 프로그램에서 입력한 코드는 서버에서 검증되며, 아동 식별명과 기록은 프로그램별로 분리하여 Supabase에 저장됩니다. 기존 설명글 기록은 변경하지 않습니다.
